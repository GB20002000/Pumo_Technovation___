# Pumo Technovation – Android app

## Get the APK (no Android Studio needed)
1. Create a free account at https://github.com and make a new repository.
2. Upload ALL files from this folder (including the hidden `.github` folder) and commit to `main`.
3. Open the **Actions** tab > "Build Android APK" > wait ~5 minutes for the green tick.
4. Open the finished run > **Artifacts** > download `PumoTechnovation-apk` (a zip containing `app-debug.apk`).
5. Send `app-debug.apk` to your phone and install it (allow "Install unknown apps").

## Or with Android Studio
Open this folder, wait for sync, then Build > Build APK(s).

## Updating the website
Edit files in `app/src/main/assets/` and push again – a new APK is built automatically.
